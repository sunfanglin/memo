# 报告正文

## 已开展的工作
### 概况
- 基于机器学习的未来情景高分辨率气温数据产品研制
- 基于历史气数据分析青藏高原极端高温分布特征
### 未来情景高分辨率气温数据
#### 背景
青藏高原有着中低纬度地区面积最大的多年冻土分布，其地面承载力、地下冰和热状态随地形变化迅速，而CMIP产品提供的未来1° 日平均气温无法分辨河谷与山脊、阳坡与阴坡，难以支撑气候暖湿化背景下的青藏高原大型基础设施建设中涉及的路基、塔基和能源台址评估。
本项目的关键工作即是基于机器学习方法和真实地形来制作未来情景下的高分辨率地表气温数据，数据空间分辨率为4-10km，时间分辨率为1-3小时。
#### 实施
- [x] **模型测试**,直接采用CONUS预训练模型、把约1° 的CMIP气候模式资料降尺度到名义4 km 的方案;
- [x] **本地化训练调试**，使用高原区域 HARv2 降尺度数据作为训练数据，制作本地化模型权重，产品分辨率设定为10 km（减少训练时间）；
- [ ] **本地化应用**，基于已试验通过的方法，使用1/30度的 CMFD 数据产品来训练模型，进而制作 4km 分辨率气温产品

### 基于历史气温数据分析青藏高原极端高温分布特征
- [x] **历史数据收集**，第一是第三极地区 1979–2023 年 1/30° 地面气象要素数据，包含月、日、小时尺度，覆盖降水、气温、比湿、风速、气压和辐射；其中气温等要素融合了短期高分辨率 WRF、长序列 ERA5 和站点观测，并集成了 TPHiPr 降水与 ISCCP 辐射产品。第二是中国区域地面气象要素驱动数据集 CMFD 2.0，时间为 1951–2024 年，分辨率为 0.1°、3 小时。第三是 IMERG 卫星降水，空间分辨率约 0.1°。
- [x] **极端高温分析**，项目利用长序列气温资料，分析了近 50 年高原极端高温出现天数的变化，并比较了全区、东南部、中北部以及青藏铁路沿线的差异。
## 主要进展
数据研制使用 MRI-ESM2-0 和 TaiESM1 两个模式的 historical（2010–2014）和 SSP2-4.5（2045–2049）日资料，以 ERA5 月气候态做偏差订正，以 HAR v2 训练时间模型，并以 ETOPO 地形贯穿训练和推理。网格对齐到 26–40°N、80–104E。
项目已完成模型训练和四套逐小时产品，随后开展了气候态评价、时间接缝诊断和日平均守恒检查。

- 第一，项目已经完成一套可运行、可检查的 10 km 逐小时气温试验流程。从模式资料准备、月偏差订正、地形物理降尺度、时间模型训练，到产品评价和增暖分析，均在同一套网格上完成。同时，项目依据递减率和日变化评价结果，修复了早期网格偏移，设置了独立验证集，并用重叠生成窗口减轻时间接缝。现有产品覆盖两个模式的历史时期和未来情景。
- 第二，试验产品通过了既定的气候态评价门槛。评价对象是多年气候态，而不是要求某一小时与再分析逐时对应。夏季日较差达到 ERA5-Land 参考值的约 78–79%；未来增暖符号与 1° 输入保持一致。中东部两模式等权年平均增暖约为 +1.94°C，相应 1° 输入为 +1.88°C，其中冬季增暖最强，较强增暖区位于青海东部。按真实接缝时刻重计后，区域平均时间接缝比值低于标志阈值。
- 第三，极端高温趋势分析给出了初步结论。近 50 年来，青藏高原极端高温出现天数总体呈上升趋势。从区域上看，高原东南部上升最为显著，青藏铁路所在的中部北部为第二显著区域。单独统计铁路沿线 100 km 范围，年极端高温天数的增加趋势高于高原平均水平。该结果与中东部试验产品中冬季增暖较强、青海东部出现热点的认识可以相互对照，说明交通走廊的热风险应当作为后期应用分析的优先对象。
